# Eastside Stringer (Starter)

This repository will host a minimal Next.js + TypeScript + Tailwind scaffold for an information-only site for a racket stringing business.

Pages included in the scaffold I will push:
- Home
- Services
- Gallery
- Contact

To run the scaffold locally (after I push the scaffold branch or you get the files):
1. npm install
2. npm run dev

I will push a branch named `scaffold/nextjs-tailwind` with the starter project once this initial commit exists.
